# Radio Recorder – Version 0.2.0

## Neu
- Aufnahmedauer als Stunden + Minuten
- Bis zu 24 Stunden pro Aufnahme
- Laufzeitanzeige bei laufender Aufnahme
- Erweiterte FFmpeg-Wiederverbindung bei Netzwerk-/HTTP-Fehlern
- SUNSHINE LIVE 192 kbit/s
- Speicherung standardmäßig nach `/media/Musick/Radioaufnahmen`

## Installation / Update
Den Ordner `radio_recorder` nach `/addons/radio_recorder` kopieren.
Wenn Version 0.1.0 bereits installiert ist, Dateien ersetzen, den Add-on-Store neu laden und anschließend aktualisieren bzw. neu installieren.

Für einen Test z. B.:
- 4 Stunden = Stunden 4, Minuten 0
- 5 Stunden = Stunden 5, Minuten 0
- 12 Stunden = Stunden 12, Minuten 0
